# LearnLingo

LearnLingo is a responsive web application designed to help users find and book language tutors. Users can browse teacher profiles, filter tutors by their preferences, save favorite teachers, and request trial lessons.

The project was developed using Next.js, React, TypeScript, and Firebase.

## Features

- Browse language tutors and view their profiles.
- Filter teachers by language, knowledge level, and hourly price.
- Load additional teachers using the **Load more** button.
- View detailed teacher information and student reviews.
- Register, log in, and log out using Firebase Authentication.
- Add and remove teachers from Favorites.
- Save favorite teachers between page reloads.
- Access a private Favorites page.
- Open a trial lesson booking modal with validated form fields.
- Use the application on mobile, tablet, and desktop devices.

## Technologies

- **Next.js** — application framework and routing.
- **React** — user interface development.
- **TypeScript** — static typing.
- **CSS Modules** — component styling.
- **Firebase Authentication** — user authentication.
- **Firebase Realtime Database** — teacher data storage.
- **TanStack Query** — data fetching, caching, and pagination.
- **Zustand** — client-side state management.
- **React Hook Form** — form handling.
- **Yup** — form validation.
- **React Icons** — interface icons.
- **React Hot Toast** — notifications.
